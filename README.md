# 🌌 Personal Portfolio Website

## 📌 Project Overview
This is a single-page personal portfolio website built using HTML, CSS, and JavaScript. It showcases personal information, skills, and contact details in a clean and responsive layout with a space-themed design.

## 🚀 Features
- Responsive single-page design
- Header section with name and title
- About Me section
- Skills section
- Contact section
- Interactive JavaScript button
- Space-themed background using CSS
- Clean and modern UI

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
Portfolio/
│
├── index.html

```
